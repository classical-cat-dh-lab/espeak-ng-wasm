# Building (BUILDING.md)

> Reproducible build pipeline: upstream eSpeak NG release tag → `.wasm` + `.data` +
> driver. Same script runs locally (macOS) and in CI (ubuntu-latest).
> Status: v0.1.0-draft · 2026-08-13

## Prerequisites

- macOS (local spike) or Linux (CI):
  - `brew install autoconf automake libtool` (macOS) / `apt install autoconf automake libtool` (CI)
  - git, bash
- Emscripten SDK: clone https://github.com/emscripten-core/emsdk, `emsdk install
  <pinned-version> && emsdk activate <pinned-version>` (~2–3 GB disk).
  The pinned version is recorded in `manifest.json` after each successful build.
- Disk: ~4 GB total (emsdk + two build trees).

## Pipeline overview

Two-stage build — the data package can **only** be produced by a native build:

```
stage 1 (native):  autoreconf → autogen → configure → make        → espeak-ng-data/
stage 2 (wasm):    ucd-tools via emconfigure → libespeak-ng.la    → link with glue.c
                   via emcc → espeak-ng.{js,wasm} + trimmed .data
```

## Steps

1. **Clone & pin.** `git clone https://github.com/espeak-ng/espeak-ng`; check out the
   latest release tag; record tag + commit SHA (they go into `manifest.json`).
2. **Fix autotools bootstrap** (lesson from the ChromeOS port): `autoreconf -fvi &&
   ./autogen.sh` — plain `autogen.sh` creates symlinks to host GNU autotools files
   that break in clean environments.
3. **Native build (data stage):**
   `./configure --prefix=/usr --without-async --without-mbrola --without-sonic && make`
   The native binary is a byproduct; the goal is `espeak-ng-data/` (phondata,
   phonindex, phontab, intonations — generated by eSpeak's own compile step).
4. **Native smoke test:**
   - `src/espeak-ng -v la "arma virumque cano"` (Latin voice exists and speaks)
   - `src/espeak-ng -v la "[[...]]"` (mnemonic input path works)
   - `src/espeak-ng --ipa ...` cross-check IPA output against our expectations
   - Verify the `la` phoneme inventory covers the full G2P output set (every IPA
     symbol we emit must have a mnemonic — see INTERFACE.md §5).
5. **Cross-compile ucd-tools:**
   `cd src/ucd-tools && ./autogen.sh && make clean && emconfigure ./configure &&
   emmake make && cd ../..`
6. **Cross-compile the library:**
   `emconfigure ./configure --prefix=/usr --without-async --without-mbrola
   --without-sonic && emmake make src/libespeak-ng.la`
7. **Link wasm** with our own `glue.c` (not the upstream 2017 glue):
   ```
   emcc -O3 -sWASM=1 -sMODULARIZE=1 -sEXPORT_ES6=1 -sALLOW_MEMORY_GROWTH=1 \
        --preload-file espeak-ng-data-trimmed@/espeak-ng-data \
        -sEXPORTED_FUNCTIONS=[...] -sEXPORTED_RUNTIME_METHODS=[ccall,cwrap,FS] \
        glue.c .libs/libespeak-ng.a -o espeak-ng.js
   ```
8. **Trim data** via `trim-data.sh` (scripted, never manual — see below), then
   repackage `.data`.

## Data trimming (`trim-data.sh`)

Keep: `phondata`, `phonindex`, `phontab`, `intonations`, `voices/la` (+ minimal
`voices/!v` variants it references), `voices/default` if required.
Drop: all `*_dict` files, mbrola data, all other language voices.
Target: ≤ 2 MB trimmed; release acceptance = `.wasm` + `.data` ≤ 4 MB pre-gzip.

## Glue layer (`glue.c`, ~100 lines)

Four exported functions only: `init` (espeak_Initialize with
`AUDIO_OUTPUT_RETRIEVAL` + synth callback), `synthesize` (espeak_Synth on the mapped
`[[...]]` string, PCM accumulated via callback), `setParams`, `terminate`.
PCM: 22050 Hz / 16-bit signed / mono, whole-utterance buffered.

## Operational discipline

- Long builds run via `nohup bash build.sh > build.log 2>&1 &` with manual log
  tailing — never as agent-runtime background tasks (process-tree reaping risk).
- `build.sh` is the single source of truth: local spike and CI run the same script.
- CI: GitHub Actions, ubuntu-latest, pinned emsdk; on success upload artifacts;
  tag push → GitHub Release with `espeak-ng.wasm`, `espeak-ng.data`, `espeak-ng.js`,
  `espeak-wasm-driver.js`, `manifest.json`, `sha256sums.txt`.
- Reproducibility check: CI artifact SHA-256 must match a clean local build of the
  same tag + toolchain.

## Fallback path (if the spike stalls > 2 days)

Vendor a community build: candidate A = npm `espeak-ng@1.0.2` (ianmarmour);
candidate B = `echogarden-project/espeak-ng-emscripten`. Record source + SHA-256,
run the full acceptance suite, ship LICENSE alongside. Same acoustics (same
codebase), same acceptance criteria.

## Acceptance criteria

1. Clean-machine reproducibility (CI green, checksums match local).
2. Functional: ≥ 20 gold-standard IPA strings synthesize without error, PCM
   non-silent (RMS above threshold, checked programmatically), plausible durations.
3. Human spot-check: 5–10 items (incl. Aeneid I.1–7) reviewed by ear for phoneme
   identity and stress placement. (Robotic timbre is inherent to formant synthesis —
   not an acceptance item.)
4. Offline: after SW pre-cache, `playIPA` works with network disabled.
5. Size: `.wasm` + `.data` ≤ 4 MB pre-gzip.
